HOW I'D DESCRIBE THIS PROJECT
I built a cloud-based food delivery data platform using AWS S3 and Snowflake, with dbt handling modeling and data-quality testing, and Airflow orchestrating the pipeline end to end. Processing is incremental and idempotent. Snowflake RBAC and PII masking cover governance, and GitHub Actions run CI on every pull request. The curated Snowflake marts power both analytical dashboards and an AI layer — review enrichment, a RAG-based review chat, and text-to-SQL.
